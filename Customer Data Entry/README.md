# Data Entry, Cleaning & Processing Projects

## Overview
This repository contains a collection of practical projects focused on data entry, cleaning, standardization, and validation. The main goal is to showcase different methods and cloud-based spreadsheet techniques used to transform raw, unstructured, or inconsistent datasets into reliable, well-formatted bases ready for analysis.

---

## Featured Project: Customer Data Entry & Cleaning

### Project Description
This project covers the end-to-end processing of a customer dataset (`Customer Data Entry.xlsx`). Raw entry records often contain formatting errors, duplicates, and missing fields. This project demonstrates how to clean, structure, and validate the data directly within Google Sheets to ensure accuracy and consistency.

### Data Source
The dataset used for this project was obtained from [HowToCSV - Sample Customers CSV](https://howtocsv.com/sample-customers-csv/).
